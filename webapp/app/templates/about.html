About

This tool parses Arabic subtitle files (.srt), lemmatizes every word using CAMeL Tools (MLE disambiguator), and displays a sorted frequency table.

Features
  • Upload any Arabic .srt file — UTF-8 or Windows-1256 encoding supported
  • Per-user blacklist persisted in the database
  • Save and reload analysis sessions (requires Google sign-in)
  • Export results as CSV or blacklist as JSON
Tech stack
  • FastAPI · SQLAlchemy · SQLite
  • CAMeL Tools (MLEDisambiguator)
  • Bootstrap 5
