About

This tool parses subtitle files (.srt), lemmatizes every word using language-specific processors, and displays a sorted frequency table.

Features
  • Upload any subtitle .srt file
  • Save and reload analysis sessions (requires Google sign-in)
  • Export results as CSV or ignore-list as JSON
Tech stack
  • FastAPI · SQLAlchemy · SQLite
  • CAMeL Tools
  • Stanza
  • Bootstrap 5
