About

This tool parses subtitle files (.srt), lemmatizes every word using language-specific processors, and displays a sorted frequency table.

Features
  • Upload any subtitle .srt file
  • Save and reload analysis sessions (requires Google sign-in)
  • Export results as CSV or ignore-list as JSON
Language models

Lemmatization, POS tagging, and morphological analysis are delegated to the following libraries:

  • CAMeL Tools — Arabic (Modern Standard + Egyptian)
  • Stanza — English, German, Spanish, Greek
  • Wiktionary (via kaikki.org, CC BY-SA) — Greek lemma corrections
  • calamanCy — Tagalog
  • fugashi (MeCab) + UniDic — Japanese
